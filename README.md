# NekoMusic for macOS

> ⚠️ **重要警告：这是一个极度不完整的实验性项目**
>
> **请勿把它当作可用的音乐播放器。**
>
> 目前它**无法百分百正常使用**，大量核心功能缺失或未经测试：
> 登录态不持久、歌单/收藏/搜索等页面尚未实现、错误处理不完善、界面仍在频繁改动。
> 代码仅用于技术验证与学习交流，随时可能发生破坏性变更。

NekoMusic 的 macOS 原生客户端，使用 SwiftUI 构建，对接 NekoMusic 曲库服务。
不带任何音源，曲库、账号、播放全部由后端提供。

## 当前进度（诚实版）

### 已实现且验证过

- 首页：排行榜 / 最新上架卡片网格，悬停放大 + 播放按钮浮现
- 播放：音频解析、播放/暂停/上下曲/进度拖动、音量
- **ID3 内嵌元数据读取**：直接从音频文件读封面与歌词，无需额外接口（Range 请求 256KB）
- 播放页（独立窗口）：封面模糊背景、歌词自动滚动居中、当前行高亮
- 迷你播放器窗口：封面 + 歌词
- 外观：深浅色、主题色、壁纸（含模糊/遮罩）、歌词字号
- 底部浮动播放条：封面主色调渐变

### 未实现 / 不可用

| 功能 | 状态 |
|---|---|
| 登录 / 注册界面 | 界面在，**未完整测试** |
| 扫码登录（手机确认） | 代码在，**未验证** |
| 搜索页 | ❌ 未实现 |
| 音乐库 / 我的歌单 | ❌ 未实现 |

## 构建

```bash
git clone <repo>
cd NekoMusicMac
open NekoMusicMac.xcodeproj
```

- Xcode 27+，macOS 15+
- 工程文件由 `gen_project.py` 生成（新增 Swift 文件后重跑一次）
- 无 SPM / CocoaPods 依赖
